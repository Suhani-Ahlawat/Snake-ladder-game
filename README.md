# 🐍 Snake and Ladder Game in C

## Project Overview
A simple two-player Snake and Ladder game developed using C programming. Players take turns rolling dice and moving across the board. The first player to reach exactly 100 wins.

## Features
- Two-player gameplay
- Random dice rolls from 1 to 6
- Snakes move players down
- Ladders move players up
- Player position tracking
- Automatic winner detection

## Technologies Used
- **Language:** C
- **Editor:** Visual Studio Code
- **Compiler:** GCC / Clang

## How to Run on MacBook

Compile:

`gcc snake_ladder.c -o snake_ladder`

Run:

`./snake_ladder`

## How to Play
1. Press Enter to roll the dice.
2. Your position increases according to the dice roll.
3. Landing on a ladder moves you upward.
4. Landing on a snake moves you downward.
5. Reach exactly 100 to win.

## C Concepts Used
- Arrays
- Loops
- Conditional statements
- Random number generation
- Input/output functions

## Conclusion
This project demonstrates basic game logic using C programming and is suitable for beginners learning arrays, loops, and conditional statements.
